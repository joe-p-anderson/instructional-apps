# An Activity is built on exactly one Tool; distinct interactions are Modes of that Tool

When an Activity's Parts need different interactions, they become Modes of a single Tool. In conductor_properties those are electric field, potential, and Gauss's law. The alternative was an Activity that mounts a different Tool per Part. We chose a single Tool with Modes so that each Activity has one Tool to load, and so that Standalone mode for that Tool covers the whole topic (one tab per Mode) instead of being split across several tools.

## Consequences

A Tool must support being mounted several times on one page, because each Part keeps its own State even when two Parts use the same Mode. Topics that span loosely related interactions produce larger Tools.
