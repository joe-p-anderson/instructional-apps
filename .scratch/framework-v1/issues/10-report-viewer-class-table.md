# 10: Report Viewer: class table from a Brightspace zip

Spec: docs/specs/0001-framework-v1.md (vocabulary from GLOSSARY.md; respects ADRs 0001–0003).

**What to build:** The instructor drops the Brightspace bulk-download zip (or many Reports) onto the Report Viewer and sees the whole class in one table, with a detail page per student and scores recomputed from the Attempts.

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] A small zip reader, vendored or loaded from a pinned CDN version, reads the bulk download entirely in the browser
- [ ] Each Report is matched to its uploader using the zip's folder and file names
- [ ] Class table: name, Tasks passed, Attempts, points, and a flags column (populated by ticket 11)
- [ ] Clicking a student opens their full detail (Attempts, State at each Attempt, answers, snapshots)
- [ ] Scores recomputed from the Attempts rather than trusted from the Report's stored totals
- [ ] Node tests with fixture Reports generated by the runner core, plus uploader names shaped like a Brightspace bulk download
