Encode answer keys

Paste a Condition, or one Question key (an answer, tol or correct value), as a JavaScript expression. Put the encoded string in the Activity in its place. Encoding only deters casual reading of the page source (ADR 0001).

Examples: { state: 'phi', target: Math.PI / 2, tol: 0.05, targetLabel: 'π/2 ≈ 1.571 rad' }, 3, 'b'. In the console: encodeKey(value) and decodeKey(string).
